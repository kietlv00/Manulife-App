# Nền Tảng Ôn Thi Thông Minh (Luyện Đề Trực Tuyến)

Hệ thống ứng dụng web luyện thi trắc nghiệm trực tuyến, hỗ trợ quản lý ngân hàng câu hỏi, import đề thi từ file Word/PDF, lưu trữ câu hỏi làm sai và đồng bộ dữ liệu qua Supabase[cite: 11, 12, 14].

---

## 🚀 Tính Năng Chính

### 1. Dành cho Thí sinh / Người dùng (User)

- **Đăng nhập & Quản lý phiên làm việc**: Đăng nhập bằng tài khoản để làm bài[cite: 11]. Hệ thống tự động bảo vệ màn hình thi và ngăn chặn đăng nhập đồng thời từ thiết bị khác[cite: 11].
- **Luyện đề thi trắc nghiệm**:
  - Tự động xáo trộn (random) thứ tự câu hỏi khi bắt đầu thi[cite: 11].
  - Bộ đếm thời gian làm bài ngược kèm cảnh báo khi sắp hết giờ[cite: 11].
  - Tự động nộp bài khi hết thời gian[cite: 11].
  - Thanh tiến độ hiển thị số câu đã làm và Pop-up bảng câu hỏi (1 - N) giúp chuyển câu nhanh chóng[cite: 11].
  - Cảnh báo xác nhận khi muốn nộp bài sớm hoặc chuyển về trang chủ/đăng xuất trong lúc làm bài[cite: 11].
- **Xem kết quả & Chi tiết bài làm**:
  - Tính điểm tự động, thống kê số câu đúng, câu sai và thời gian hoàn thành[cite: 11].
  - Trang **Xem lại bài làm** hỗ trợ bộ lọc: _Tất cả câu hỏi_, _Câu làm sai_, _Câu làm đúng_[cite: 11].
- **Kho / Ngân hàng câu sai (Lưu tại máy)**:
  - Tự động ghi nhớ các câu hỏi làm sai vào `localStorage`[cite: 11].
  - Lọc danh sách câu sai theo từng môn học[cite: 11].
  - Chế độ **Ôn luyện câu sai**: Tạo đề thi tùy chỉnh từ các câu làm sai để luyện lại[cite: 11].

---

### 2. Dành cho Quản trị viên (Admin)

- **Quản lý Môn học**: Thêm môn học mới hoặc xóa môn học (kèm xóa toàn bộ đề thi thuộc môn đó)[cite: 11].
- **Import Đề thi tự động (Word / PDF)**:
  - Hỗ trợ tải lên file `.docx` hoặc `.pdf`[cite: 11, 12].
  - Tự động phân tích cấu trúc đề, nhận diện câu hỏi, các phương án lựa chọn và đáp án đúng (dựa trên highlight, gạch chân hoặc chữ đỏ trong file)[cite: 11, 12].
  - Cho phép xem trước (preview) và chỉnh sửa nhanh đáp án trước khi lưu[cite: 11].
- **Quản lý & Chỉnh sửa đề thi (CMS)**:
  - Sửa tên đề thi, thời gian làm bài[cite: 11].
  - Sửa nội dung câu hỏi, phương án, chọn lại đáp án đúng hoặc xóa câu hỏi[cite: 11].
  - Xóa đề thi trực tiếp khỏi cơ sở dữ liệu Supabase[cite: 11].

---

## 🛠️ Công Nghệ Sử Dụng

- **Frontend**: React (Vite), CSS3[cite: 11, 13].
- **Backend & Database**: Supabase (Xác thực người dùng, lưu trữ danh sách môn học & đề thi)[cite: 11, 14].
- **Xử lý File & Đọc đề thi**:
  - `mammoth` & `JSZip`: Trích xuất và đọc cấu trúc XML file Word (`.docx`)[cite: 12].
  - `pdfjs-dist`: Trích xuất nội dung văn bản file `.pdf`[cite: 12].
- **Lưu trữ nội bộ**: `localStorage` (Lưu phiên làm việc và Ngân hàng câu sai)[cite: 11].

## ⚙️ Hướng Dẫn Cài Đặt & Chạy Project

### 1. Cài đặt Dependencies

Mở Terminal tại thư mục project và chạy lệnh:

```bash
npm install
```

### 2. Thiết lập Database trên Supabase

Truy cập vào dự án của bạn trên Supabase Dashboard (https://supabase.com/), mở mục SQL Editor và chạy đoạn script sau để khởi tạo các bảng dữ liệu:

-- 1. Bảng Môn học
CREATE TABLE subjects (
id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
name TEXT NOT NULL UNIQUE,
created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()) NOT NULL
);

-- 2. Bảng Đề thi
CREATE TABLE exams (
id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
subject_id BIGINT REFERENCES subjects(id) ON DELETE CASCADE,
title TEXT NOT NULL,
duration INT NOT NULL DEFAULT 45,
created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()) NOT NULL
);

-- 3. Bảng Câu hỏi
CREATE TABLE questions (
id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
exam_id BIGINT REFERENCES exams(id) ON DELETE CASCADE,
question_text TEXT NOT NULL,
options JSONB NOT NULL,
correct_option INT NOT NULL,
created_at TIMESTAMP WITH TIME ZONE DEFAULT TIMEZONE('utc'::text, NOW()) NOT NULL
);

### 3. Cấu hình Supabase trong ứng dụng

Mở file src/supabase.js và cập nhật thông tin URL và ANON_KEY của bạn:
const SUPABASE_URL = "[https://your-supabase-url.supabase.co](https://your-supabase-url.supabase.co)";
const SUPABASE_ANON_KEY = "your-supabase-anon-key";

### 4. Khởi chạy ứng dụng

Chạy lệnh dev để mở ứng dụng ở môi trường local:

```bash
npm run dev
```

Sau đó truy cập đường dẫn do Vite cung cấp (thường là http://localhost:5173).
